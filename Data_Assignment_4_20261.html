  1. Question

    Download this csv file and import it into RStudio.

    The file contains the daily adjusted price for a stock (ticker symbol MCD), and annual risk-free rates per calendar year: RF_annual.

    Suppose today is the last day in the sample, and you evaluate an at-the-money call option on the stock with the following parameters:

    • Time to expiration: 227 days
    • Sigma: stock volatility in the last calendar year (annualize with 252 trading days)

    Using the one-period binomial model, compute and report the stock price in the ‘down state’ in 227 days.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The answer is: 110.2387

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    stepsize = 227/252
lastdate = max(df$date, na.rm=T) #save last sample day (today)

dfactor = df |>
  mutate(re = log(price) - lag(log(price))) |> #log returns
  group_by(year) |>
  mutate(sigma_annual = sd(re, na.rm = TRUE) * sqrt(252)) |> #annualized vola
  filter(date == lastdate) |>
  mutate(d = exp(-sigma_annual * sqrt(stepsize))) |>
  mutate(price_d = price*d)

print(round(dfactor$price_d, digits=4))

  2. Question

    Download this csv file and import it into RStudio.

    The file contains the daily adjusted price for a stock (ticker symbol JNJ), and annual risk-free rates per calendar year: RF_annual.

    Suppose today is the last day in the sample, and you evaluate an at-the-money call option on the stock with the following parameters:

    • Time to expiration: 151 days
    • Sigma: stock volatility in the last calendar year (annualize with 252 trading days)

    Using the one-period binomial model, compute and report the hedge ratio of the call.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The answer is: 0.5336

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    stepsize = 151/252
lastdate = max(df$date, na.rm=T) #save last sample day (today)
strike   = subset(df$price, df$date == lastdate) #at-the-money

dfbihedge = df |>
  mutate(re = log(price) - lag(log(price))) |> #log returns
  group_by(year) |>
  mutate(sigma_annual = sd(re, na.rm = TRUE) * sqrt(252)) |> #annualized vola
  filter(date == lastdate) |>
  mutate(price_u = price * exp(sigma_annual * sqrt(stepsize))) |>
  mutate(price_d = price * exp(-sigma_annual * sqrt(stepsize))) |>
  mutate(c_u = max(price_u - strike, 0)) |> 
  mutate(c_d = max(price_d - strike, 0)) |>
  mutate(hr = (c_u - c_d)/(price_u - price_d))

print(round(dfbihedge$hr, digits=4))

    Solution

    strike   = 162.83

lastdate = max(df$date, na.rm=T) #save last sample day (today)

dfBSM = df |>

lastdate = max(df$date, na.rm=T) #save last sample day (today)

dfelast = df |>

  6. Question

    Download this csv file and import it into RStudio.

    The file contains the daily adjusted price for a stock (ticker symbol C), and annual risk-free rates per calendar year: RF_annual.

    Suppose today is the last day in the sample, and you evaluate a put option on the stock with the following parameters:

    • Time to expiration: 149 days
    • Strike price: 92.71
    • Sigma: stock volatility in the last calendar year (annualize with 252 trading days)

    Looking at the market price of the put, you realize that the option is underpriced with an annualized implied volatility for 2022 of 0.2316. You believe in ‘your Sigma’ (estimated as defined above) and therefore decide to buy 1 contract of puts.

    Using the Black, Scholes, and Merton model, compute and report how many shares you need to buy to keep your strategy delta neutral. (Hint: think twice about the hedge ratio.)

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The answer is: 49.7602

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    strike   = 92.71
time     = 149/252
lastdate = max(df$date, na.rm=T) #save last sample day (today)

dfdneutral = df |>
  mutate(re = log(price) - lag(log(price))) |> #log returns
  group_by(year) |>
  mutate(sigma_annual = sd(re, na.rm = TRUE) * sqrt(252)) |> #annualized vola
  filter(date == lastdate) |>
  mutate(d1 = (log(price/strike) + (RF_annual + ((sigma_annual)^2)/2)*time)/(sigma_annual*sqrt(time))) |>
  mutate(Nd1 = pnorm(d1)) |>
  mutate(shares_long = abs(Nd1-1) * 100) #for a contract of 100 puts

print(round(dfdneutral$shares_long, digits=4))

    The lower implied volatility is the reason for you to buy the underpriced put (and it ultimately determines the profit of your strategy). However, as you do not believe in the implied volatility, but rather in your own vola estimate, the latter determines your hedge ratio for a delta-neutral strategy.
