  1. Question

    Download this csv file and import it into RStudio.

    Column re_PG contains monthly total stock returns. Column tbill contains monthly returns of the 4-week T-bill.

    Compute and report the Negative 2-Sigma Ratio of the monthly stock returns over the whole period.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235.


    Solution

    The Negative 2-Sigma Ratio is: 1.0989

    The ratio is computed like the Negative 3-Sigma Ratio, but with 2 standard deviations below the mean. Note that the ratio is computed with total returns, not with excess returns.

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    dfn2s = df |>
  mutate(re_av = mean(re_PG, na.rm=T)) |>
  mutate(re_sd = sd(re_PG, na.rm=T)) |>
  mutate(re_n2 = re_av-2*re_sd) |>
  mutate(sub   = ifelse(re_PG<re_n2, re_PG, NA_real_)) |>
  summarize(N = n(), 
            n_sub = sum(!is.na(sub))) |>
  mutate(p_sub = n_sub/N) |>
  mutate(p_exp = pnorm(-2, mean=0, sd=1, lower.tail=T)) |>
  mutate(n2s   = round(p_sub/p_exp, digits=4))

print(dfn2s$n2s)

  2. Question

    Download this csv file and import it into RStudio.

    Column re_CAT contains monthly total stock returns. Column tbill contains monthly returns of the 4-week T-bill. Assume the minimum acceptable return is 0.

    Compute and report the downside deviation (DD) of the monthly stock returns, as denominator of the Sortino Ratio, over the whole sample period.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235.


    Solution

    The DD is: 0.0573

    The DD is the denominator of the Sortino Ratio and can be extracted out of the respective code chunk.

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    dfdd = df |>
  mutate(rmar      = 0) |>
  mutate(rx        = re_CAT-rmar) |>
  mutate(rx_d      = if_else(rx<0, rx, 0)) |>
  mutate(rx_d2     = rx_d^2) |>
  summarize(DD     = sqrt(mean(rx_d2, na.rm=T))) |>
  mutate(DD        = round(DD, digits=4))

print(dfdd$DD)

  3. Question

    Download this csv file and import it into RStudio.

    The file contains stock ticker symbols, date, year, month, and:

    • monthly total returns of ticker in Column re

    • monthly T-bill returns in Column tbill

    • monthly Tips returns in Column tips

    For each stock, compute the monthly Sharpe ratio, using the whole sample period, once with the T-bill and once with the Tips return as risk-free rate.

    Report the highest of all Sharpe ratios.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The Sharpe ratio is: 0.2199

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    dfshrp = df |>
  mutate(rx_sh = re-tbill) |>
  mutate(rx_lg = re-tips) |>
  group_by(ticker) |>
  summarize(sharpe_sh = mean(rx_sh, na.rm=T)/sd(rx_sh, na.rm=T),
            sharpe_lg = mean(rx_lg, na.rm=T)/sd(rx_lg, na.rm=T))

    Then view the results with View(dfshrp) and pick the highest ratio, or compute in addition:

    dfshrp = dfshrp |>
  summarize(sharpe_shmx = max(sharpe_sh, na.rm=T),
            sharpe_lgmx = max(sharpe_lg, na.rm=T),
            max_value   = max(sharpe_shmx, sharpe_lgmx, na.rm=T)) |>
  mutate(max_value      = round(max_value, digits=4))
  
print(dfshrp$max_value)

  4. Question

    Download this csv file and import it into RStudio.

    Column re_CAT contains monthly total stock returns. Column tbill contains monthly returns of the 4-week T-bill.

    An investor holds a complete portfolio of one risky asset (the stock in this data set) and one risk-free asset (the T-bill in this data set) with an optimal weight of 0.5 in the stock.

    Use the whole sample period to compute the monthly mean and standard deviation (SD) of the risky asset; then annualize the mean and SD.

    Use the formula for the optimal weight in the risky asset to solve for and compute the risk aversion parameter A.

    Report the level of risk aversion A of the investor.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235.


    Solution

    The level of risk-aversion A is: 3.7857

    The optimal weight in the risky asset, given A is ystar = rx_exp / (A * rx_sd^2). Solving for A yields A = rx_exp / (ystar * rx_sd^2).

    To compute rx_exp and rx_sd, replicate the analysis below in R. Load the tidyverse package, import the csv file (named df in the code below), and compute:

    ystar = 0.5

rx_exp = (1 + mean(df$re_CAT-df$tbill, na.rm=T))^12 -1
rx_sd  = sd(df$re_CAT-df$tbill, na.rm=T) * sqrt(12)
A = rx_exp / (ystar * rx_sd^2)
A = round(A, digits=4)

print(A)

  5. Question

    Download this csv file and import it into RStudio.

    The file contains stock ticker symbols, date, year, month, and:

    • monthly total returns of ticker in Column re

    • monthly 4-week T-bill yields in Column tbill

    Your friend wants to make an investment of 3000 Euro into one of these stocks today, based on your forecast for the next 8 months.

    For each stock, using the whole sample period,

    • compute an unbiased forecast of the monthly return, and

    • forecast the total, compounded value of your friend’s investment at the end of the 8 months.

    Report the highest of the forecasted Euro amounts. For example, if the investment of 3000 Euro into the best performing stock is forecasted to generate 3370.37 Euro after 8 months, then please report 3370.37, rounded to two decimals.

    Note: Enter your answer as a single number, rounded to two digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 1200.129 should be entered as 1200.13. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The highest forecasted amount is: 3343.56

    Note that the value of your friend’s investment grows with the total return re, which includes the risk-free return. Therefore, we do not need to compute excess returns (tbill-re). To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    f   = 8
inv = 3000

dffrcst = df |>
  group_by(ticker) |>
  summarize(n        = n(),
            re_geom  = prod(1+re, na.rm=T)^(1/n) - 1,
            re_arthm = mean(re, na.rm=T)) |>
  mutate(re_mth      = re_geom*f/n + re_arthm*(n-f)/n) |>
  mutate(inv_cmp     = inv * (1+re_mth)^f)

    Then view the results with View(dffrcst) and pick the highest amount, or compute in addition:

    dffrcst = dffrcst |>
  summarize(inv_max  = max(inv_cmp, na.rm=T)) |>
  mutate(inv_max = round(inv_max, digits=2))

print(dffrcst$inv_max)

  6. Question

    Download this csv file and import it into RStudio.

    All columns (except the first one) contain monthly excess stock returns of the tickers in the column name rx_[ticker]. The stocks are part of a portfolio with the following weights (in the order of the tickers): 0.1, 0.1, 0.2, 0.3, 0.3

    Using matrix multiplication, compute the monthly portfolio risk over the whole sample period.

    Report the monthly standard deviation of the weighted portfolio.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235.


    Solution

    The portfolio standard deviation is: 0.0576

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    pweights = c(0.1, 0.1, 0.2, 0.3, 0.3)

rx_stocks = df |> select(-date)
covMatrix = rx_stocks |> cov(use = 'pairwise.complete.obs')
port_std = sqrt(t(pweights) %*% covMatrix %*% pweights)
port_std = round(port_std, digits=4)

print(port_std)
