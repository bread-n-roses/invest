  1. Question

    Download this csv file and import it into RStudio.

    The file contains daily total returns re from 2019 to 2022 for a stock (ticker symbol PG), the SP500 index returns, and daily risk-free returns rf.

    Using the whole sample period, compute and report the CAPM beta for the stock.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The beta of the stock is: 0.6299

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    dfbeta = df |>
  mutate(rx = re-rf) |>
  mutate(rm = SP500-rf)

lm_beta = lm(rx ~ rm, data = dfbeta)

beta = coef(lm_beta)["rm"]

print(round(beta, digits=4))

    Alternatively, after having estimated model lm_beta, you can also visually inspect the results with coef(lm_beta) or summary(lm_beta), and report the coefficient for rm.

  3. Question

    Download this csv file and import it into RStudio.

    The file contains daily excess returns rx for a stock with ticker symbol AXP, and the corresponding daily excess returns of the three Fama-French Factors “Market” MKT, “Small minus Big” SMB, and “High minus Low” HML.

    Using all observations until the end of 2021 estimate the FF3-factor model. Then, using these estimates, compute and report the cumulative abnormal return (CAR) for the stock in 2022.

    Report the CAR for 2022.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    The CAR for 2022 is: -0.4295

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    lm_FF3 = lm(rx ~ MKT + SMB + HML, data = df, subset = (year<=2021))

df$rx_pred = predict(lm_FF3, newdata = df)

dfar = df |>
  mutate(ra = rx - rx_pred) |>
  filter(year==2022) |>
  summarize(car = sum(ra)) |>
  mutate(car = round(car, digits=4))

print(dfar$car)

    Alternatively, instead of |> summarize(), you can use |> mutate(car = sum(ra)) or |> mutate(car = cumsum(ra)) and visually inspect the car at the end of 2022.

  6. Question

    Download this csv file and import it into RStudio.

    The file contains daily excess returns rx for a stock with ticker symbol MMM, and the corresponding daily excess returns of the three Fama-French Factors “Market” MKT, “Small minus Big” SMB, and “High minus Low” HML.

    Using all observations until the end of 2021 estimate the FF3-factor model. Then, using these estimates, compute and report the cumulative abnormal return (CAR) for the stock in 2022. Compute Patell’s (1976) t-statistic of that CAR, based on all abnormal returns until the end of 2020.

    Report Patell’s t-value.

    Note: Enter your answer as decimals, rounded to four digits to the right of the decimal point. Use periods for decimal points, not commas. For example: 0.123499 should be entered as 0.1235. If your answer is a negative number, enter the number with a leading minus sign.


    Solution

    Patell’s t-value for the CAR for 2022 is: -2.3271

    To replicate the analysis in R, load the tidyverse package, import the csv file (named df in the code below), and compute:

    lm_FF3 = lm(rx ~ MKT + SMB + HML, data = df, subset = (year<=2021))

df$rx_pred = predict(lm_FF3, newdata = df)

df$ra = df$rx - df$rx_pred

dfar = df |> filter(year == 2022) |>
  summarize(car = sum(ra), car_n = sum(!is.na(ra)))

dfsd = df |> filter(year <= 2020) |>
  summarize(sd = sd(ra), sd_n = sum(!is.na(ra)))

car   = as.double(dfar$car)
car_n = as.integer(dfar$car_n)
sd    = as.double(dfsd$sd)
sd_n  = as.integer(dfsd$sd_n)

t_stat = car / (sd * sqrt(car_n*(1+1/sd_n)))

print(round(t_stat, digits=4))

    Alternatively, you can also use Base R with car = sum(df$ra[df$year==2022]) and car_n = sum(!is.na(df$ra[df$year==2022])) and sd = sd(df$ra[df$year<=2020]) and sd_n = sum(!is.na(df$ra[df$year<=2020])).
