  1. Question

    Assume you have a data file, named df, with two columns (2 variables) and 120 monthly observations (120 rows). Column re contains monthly total stock returns and Column tb monthly returns of the 4-week T-bill.

    Then you run the R code below:

    df = df |>
      mutate(
        RA = mean(re, na.rm = TRUE),
        RS = sd(re, na.rm = TRUE),
        S = ifelse(re < RA-RS, re, NA_real_)) |>
      summarize(N = n(), NS = sum(!is.na(S))) |>
      mutate(
        PS = NS / N,
        PE = pnorm(-1, mean=0, sd=1, lower.tail=T),
        sol = PS / PE)

    Which type of measure did you compute with the variable sol?


    1. Expected Shortfall
    2. Negative Sigma Ratio
    3. Value at Risk
    4. None of these measures

    Solution

    1. False.
    2. True. The code computes a Negative 1-Sigma Ratio with the probability of re being smaller than 1 sd below the mean (RA-RS). This probability is computed as PS=NS/N, and then put in relation to the corresponding probability for the normal distribution, stored in PE.
    3. False.
    4. False.

  3. Question

    You have the following variance-covariance matrix of AMZN and MCD returns, saved in matrix format as COV_MAT in R:

    AMZN MCD
    AMZN 0.7 0.8
    MCD 0.8 0.5

    What is the value of SOL in the code below?

    PWEIGHTS = c(0.6, 0.4)
    PVAR = t(PWEIGHTS) %*% COV_MAT %*% PWEIGHTS
    SOL = round(PVAR, digits=2)

    Note: Enter your answer as decimals (no percentages), rounded to two (2) digits to the right of the decimal point. Use periods for decimal points, not commas. Example: If your solution is 53.367, enter your answer as 53.37. (Enter negative numbers with a leading minus sign.)


    Solution

    The solution is 0.72.

    Transpose the weights for the matrix multiplication:

    0.6x0.7 + 0.4x0.8 = 0.74

    0.6x0.8 + 0.4x0.5 = 0.68

    Then multiply the resulting vector with the (non-transposed) weights again:

    0.6x0.74 + 0.4x0.68 = 0.72
